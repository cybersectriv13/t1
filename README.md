# Learning / integrating IaC.

## Overview
This project is a hands-on lab for getting comfortable with the core Terraform workflow. Provider configuration, resource definitions, state management, and plan/apply/destroy — using Azure.

## What is Deployed
An Azure resource group and virtual network are the focus of the deployment.

## Prerequisites
- Terraform
- Azure subscription
- Azure CLI (authenticated)

## Usage
terraform init
terraform plan
terraform apply
terraform destroy

## Notes
Previously, I used the Azure portal strictly to create resources and build out an environment. Focusing on becoming more efficient with automation to scale environments as needed. The goal is to become more familiar with Terraform's declarative resource model and push code faster.
