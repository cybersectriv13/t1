# Learning / integrating IaaC.

## Overview
This project is a hands-on lab for getting comfortable with the core Terraform workflow. Provider configuration, resource definitions, state management, and plan/apply/destroy — using Azure.

## What's Deployed
An Azure resource group, and virtual network are the focal point for the deployment.

## Prerequisites
- Terraform
- Azure subscription
- Azure CLI (authenticated)

## Usage
terraform init
terraform plan
terraform apply
terraform destroy

## Notes
Previously I used strictly the Azure portal to create resources and build out an environment. Focusing on becoming more efficient with automation to scale environments as needed. With continued practice, I'll become more familiarized with Terraform's declarative resource model and be able to push code faster.
